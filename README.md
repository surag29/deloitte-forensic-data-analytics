| | |

---

## 🧩 Task Breakdown

### Task 1 — Operational Downtime Analysis (Tableau)
Built an interactive Tableau dashboard to explore factory and device-level operational downtime.

- Visualized downtime trends across multiple factories and device types
- Enabled interactive drill-down to identify where and when downtime concentrated
- Surfaced patterns not obvious from raw tabular data alone

📊 Deliverable: Interactive Tableau dashboard

### Task 2 — Workforce Equality Classification (Excel)
Classified employee-level equality data using Excel formulas to support a discrimination/fairness assessment.

- Applied formula-based logic to categorize records into defined equality/fairness categories
- Summarized classification results to support a business conclusion
- Practiced the kind of structured, auditable data handling expected in forensic and compliance-adjacent analytics work

📄 Deliverable: Classified dataset + summary findings (Excel)

---

## 🔍 Approach

Each task mirrors a real deliverable a Deloitte analyst might produce: a stakeholder-facing visual (Tableau) for spotting operational trends, and a structured, defensible dataset (Excel) for a sensitive classification task where consistency and auditability matter as much as the conclusion itself.
